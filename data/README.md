|---|---|---|

## Real data: regulator (`sample/regulator/`)

Source: [data.gov.my](https://data.gov.my), Ministry of Health / NPRA open data. Licence: **CC BY 4.0**.
The data should not be used as the basis for legal action.

| File | Upstream | Rows in repo |
|---|---|---|
| `pharmaceutical_products_cancelled.parquet` | `storage.data.gov.my/healthcare/pharmaceutical_products_cancelled.parquet` | all |
| `pharmaceutical_products.parquet` | `storage.data.gov.my/healthcare/pharmaceutical_products.parquet` | seeded 2,000-row subset (`--seed 42`) |
| `pharmaceutical_importers.parquet` | `storage.data.gov.my/healthcare/pharmaceutical_importers.parquet` | all |
| `pharmaceutical_wholesalers.parquet` | `storage.data.gov.my/healthcare/pharmaceutical_wholesalers.parquet` | all |

Fetch date, row counts and checksums are in `sample/regulator/manifest.json`. Regenerate with:

```bash
python scripts/fetch_regulator.py
```

These datasets carry registration numbers (`reg_no`) but **no batch numbers**. Batch numbers come only from the NPRA recall notices (`scripts/scrape_npra.py`).

## Real data: NPRA recall notices (`sample/regulator/npra_recalls.csv`)

Source: [NPRA Product Recall page](https://www.npra.gov.my/index.php/en/consumers/safety-information/product-recall.html), one table per year from 2023. Fetched once with a single request and committed; the app never scrapes at runtime. Reuse terms for the NPRA website are not stated; we cite the source and use the snapshot for this non-commercial project only.

| Column | Meaning |
|---|---|
| `recall_id` | stable ID: hash of reg_no + raw batch text + raw date |
| `recall_date` | ISO date (English and Malay month names are parsed) |
| `reg_no` | MAL number only (notes such as "(FOR USE IN ANIMALS)" removed) |
| `batches` | parsed batch list, separated by `\|`; empty when `all_batches` is true |
| `all_batches` | the notice covers every batch |
| `batch_raw` | the cell exactly as published, lines joined with ` / ` (provenance) |
| `degree` | `I`, `II`, `III`, or empty for voluntary recalls that state no degree |
| `voluntary`, `level` | voluntary flag; recall level (`sales`, `consumer`, `sub-distributor (wholesaler)`, ...) |

Regenerate with `python scripts/scrape_npra.py`, or re-parse the saved page with `--offline`.

## Synthetic data

Inventory, POS and supplier data are **synthetic**, generated by `scripts/generate_synthetic.py --seed 42` and seeded from the real `reg_no` values above.
